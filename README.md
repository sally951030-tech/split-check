# split-check 出遊分帳工具

朋友出遊分攤費用的小工具：成員管理、花費紀錄（付款人、分攤人可不同）、自動結算，並可一鍵複製結算文字分享到 IG 群組。純前端，資料存在瀏覽器 localStorage，不需要伺服器，打開網頁就能用。

## 線上使用

https://sally951030-tech.github.io/split-check/

## 功能

- 新增/移除成員
- 新增花費：項目、金額、誰付的、由誰分攤（可勾選部分成員，不一定要全體均攤）
- 花費紀錄列表，可個別刪除，也可一鍵刪除全部（有二次確認保護）
- 自動結算：算出每人應收/應付金額，並用債務簡化演算法給出最少次數的轉帳建議
- 複製「應收/應付金額 + 建議轉帳」文字，方便貼到 IG 群組

## 本機執行

不需要安裝任何套件，直接用瀏覽器打開 `index.html` 即可。

## 資料格式（存在 localStorage）

- `sc_participants`：成員陣列 `{ id, name }`
- `sc_expenses`：花費紀錄陣列 `{ id, desc, amount, payerId, splitIds: [participantId, ...] }`

資料只存在你自己的瀏覽器裡，換裝置或清瀏覽器快取，資料就會消失。
